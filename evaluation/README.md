# Evaluation

Purpose: test questions and (later) the script that measures retrieval and answers.

- questions/target_30.csv : the 30 UCG pre-prescription verification questions. Experts fill in expected_verdict and the evidence page.
- questions/baseline_50_boundary.csv : the 50 baseline questions. Many test the edges of what the UCG covers (ICD-10 coding, cost, stock, patient data), where "not covered" is the right answer.
