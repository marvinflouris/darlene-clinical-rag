# ADR-028: Dependencies and Python version for the first pipeline steps

- Date: 2026-11-15
- Status: accepted
- Context: Steps 1 to 3 must read every line of the PDF with its font, size, position and whether it is rotated. The config files are YAML, and the code needs tests. Nothing is installed yet, and AGENTS.md says dependency changes need the owner's approval.
- Options considered: (a) PyMuPDF for the main extraction; (b) pdfplumber, which has a permissive license but is slower and reports fonts and positions in its own way; (c) poppler's pdftotext, a system program that reads sideways tables well but gives no font information.
- Decision: (a). Dependencies: pymupdf, pyyaml, and pytest as a development dependency only. JSONL, CSV, SQLite and regular expressions use Python's standard library, so pandas and openpyxl are not used in the pipeline. The Python version is 3.12, pinned with `uv python pin 3.12`. There are no upper version limits; uv resolves the latest compatible versions and uv.lock records them. PyMuPDF is imported as `pymupdf`, never as `fitz`. A second extractor for table comparison (for example pdfplumber) is decided with step 7. Stage 3 libraries get their own ADR, and the Python version is rechecked then.
- Why: All the audit work (fonts, sizes, rotated text, whole-book counts) used PyMuPDF, so the checked values in config/ come from it, and a whole-book scan took minutes. It gives font, size, position and rotation for every line in one pass. Both pymupdf and pyyaml publish packages for Python 3.12. Python 3.12 is mature and widely supported by AI libraries, which lowers the risk for Stage 3.
- License note: PyMuPDF is licensed under AGPL-3.0, and a commercial license is sold separately. This is accepted for a private portfolio project. Parsing is an offline batch step, and the runtime engine does not need PyMuPDF. Revisit before publishing the repository, turning Darlene into a product, or offering it as a service: buy the commercial license, or replace the library, which would mean re-checking every value in config/ that came from PyMuPDF. Get proper legal advice at that point.
- Consequences: pyproject.toml, .python-version and uv.lock are created. AGENTS.md lists the approved dependencies, and any other dependency needs the owner's approval. Step 6 (matching LOC values to drug lines by position) still has to be prototyped on about 10 pages, because it is the least tested use of the library. Table cells on sideways pages are not read with PyMuPDF's table finder alone; they are compared with a second extractor (see step 7).
